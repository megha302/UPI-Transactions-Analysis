# UPI-Transactions-Analysis
This project analyzes UPI transaction data using Power BI.

## Features:
- Monthly transaction trends
- App-wise Comparision (Phonepe, Gpay, Paytm)
- State-wise analysis
- Charts are available
- city-wise analysis

## Tools Used:
- Power BI
- Data Visualization
